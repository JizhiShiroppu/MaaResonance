## v2.0.0-plus.2 社区衍生增强版

基于 [DaiMao204/MaaResonance](https://github.com/DaiMao204/MaaResonance) `v2.0.0-beta.2` 构建的社区衍生增强版（遵循 AGPL-3.0-only 开源协议）。

### 本版新增与更新

- **整顿中心（监狱）自动（实验型）**
  - **9 段狱内全自动闭环**：支持在任意站点经左侧抽屉「整顿中心」远程打开，自动完成事项一览领奖、囚犯办理入住、财务中心 80% 自动补满检查与开启、黑月运输订单自动交付与无弹窗免费删单、核心建筑连升与 LV0 首建/研发后续升、双仓左侧铁盟币扩容、兑换商店冲级配方与拉普拉斯协议/胶卷兑换、原料车间预存+均衡配员+开工，以及生产车间「车间编辑」（快速编队/设组长/LV6 缝纫机升级）后按白名单轮换排产。
  - **接入「一键自动日常」（默认关闭）**：已加入 `daily-all-in-one` 可选列表（默认不弹窗并收尾回大厅），可按需随日常一并执行。
  - **面向大众的细粒度 MXU 选项**：切到「仅只读规划」自动折叠执行细节；选择「自定义勾选子模块」可展开 14 项独立复选框；支持排产时长偏好（`8h/4h/2h`）、原料车间配员策略、单趟扩仓批数与建筑连升上限，以及多档位或自定义整数铁盟币保留底线。
  - **零桦石多重硬护栏 + 离线报告 + 一键 Issue 排错包**：对电力电机页签与双仓右侧桦石页签做像素亮暗+OCR 双重 fail-closed 拦截，绝不自动消耗桦石；每次结束同步输出 `config/planning/` 离线 HTML 看板，并在 `config/planning/logs/` 自动生成脱敏专项日志与 `prison_issue_*.zip`（含已脱敏日志、`report_sanitized.json`、`issue_template.md` 与可选异常/拦截现场截图，自动轮转保留最近 10 份）。
- **自定义应用图标与 Windows EXE 图标注入**
  - 新增帕拉笛（Paladi）应用图标，打包安装时自动注入 Windows `MaaResonance.exe` 文件图标与界面图标。

### 使用与反馈

- 本功能涉及多账号与不同界面状态，首次使用建议先确认「铁盟币安全保留底线」与 14 项开关设置后再启用自动执行。
- 遇到任何问题请直接在本仓库 [Issues](https://github.com/JizhiShiroppu/MaaResonance/issues) 反馈（**切勿提交至上游原仓库**）；整顿中心问题可直接将 `config/planning/logs/prison_issue_*.zip` 拖入 Issue 正文并复制包内 `issue_template.md` 提交。
