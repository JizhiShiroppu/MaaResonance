## v2.0.0-plus.4 社区衍生增强版

基于 [DaiMao204/MaaResonance](https://github.com/DaiMao204/MaaResonance) `v2.0.0-beta.2` 构建的社区衍生增强版（遵循 AGPL-3.0-only 开源协议）。

### 本版新增与修复

- **新增「海岛（蜃息岛）自动（实验型）」（`IslandPlanScan` · 阶段 1–3A，同步接入一键自动日常可选步骤）**
  - **远程入岛与体检规划（阶段 1）**：支持从任意站点经「活动 -> 经营活动 -> 海岛物语」自动进岛，扫描 7 维游玩天数/3 天逗留差额、垃圾站、稳定指数与营运投资状况，划分建设期/过渡期/毕业日常期并生成离线 HTML 看板与脱敏排错包（`config/planning/logs/island_issue_*.zip`）。
  - **零风险日跑闭环（阶段 2）**：自动执行营运收钱、垃圾站**仅点右侧「一键收取」**（硬护栏防误点左侧一键处理、硬屏蔽垃圾站升级）、0 体力清理自家红叹号入侵怪（按实际胜场计数并支持天区消弹窗/战后刷新顶栏数据）、好友海岛清扫偷垃圾/点赞/0 体力治安助战，以及「事项一览」自动领奖（精确命中文字上方圆钮、严禁点击「追踪」、状态未变化自动中止防重复点击，并支持划开纪念卡包与结算退出）。
  - **可选建设托管与只读兑换扫表（阶段 3A）**：消费项（海角城运营投资 `auto_invest`、海岛扩建 `auto_expand`）默认全部关闭且排除在极速/全托管预设之外，仅可在自定义模式按需勾选，严格受 `reserve_coins` 留存底线、等级/资材券核验与零桦石硬护栏保护；同步支持「海岛兑换处」排球奖币/贝币与商品库存只读扫描。
- **修复「整顿中心（监狱）」电力中心退出卡放大态问题**
  - 收紧总览顶栏识别、放大聚焦态像素检测及拖拽停滞熔断，消除从电力中心建造侧面板退出后误判回到总览导致的原料/生产车间无效拖拽循环。
- **修复 `WakeUp` 开始唤醒误触大厅底栏问题**
  - 将候补盲点序列移出底栏区域（避开误入「列车电力」），并补齐截断标题/加载页识别与左上角白底黑箭头/主页返回兜底。

### 使用与反馈

- 遇到任何问题请直接在本仓库 [Issues](https://github.com/JizhiShiroppu/MaaResonance/issues) 反馈（**切勿提交至上游原仓库**）；整顿中心或海岛问题建议附上 `config/planning/logs/prison_issue_*.zip` / `island_issue_*.zip` 排错压缩包与包内 `issue_template.md`。
