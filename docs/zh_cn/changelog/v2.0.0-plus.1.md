## v2.0.0-plus.1 社区衍生增强版

基于 [DaiMao204/MaaResonance](https://github.com/DaiMao204/MaaResonance) `v2.0.0-beta.2` 构建的社区衍生增强版（遵循 AGPL-3.0-only 开源协议）。

### 新增功能与预设

- **一键自动日常（`daily-all-in-one`）**：支持按需勾选与排序执行 `WakeUp`（开始唤醒）、`DailyPrep`（邮箱 / 派遣 / 好友支援金币 / 启程签到 / 商城无垠补给周卡 / 营收排行榜点赞）、`AutoShop`（三层周期自动采购，支持按 UID 记忆刷新时间、`*N` 限购与 `^` 置顶并严格屏蔽桦石）、`CoopAssault`（共斗活动众志攻坚）、`EventStageFarm`（活动/关卡刷澄明度）、`EventStoryDaily`（糖霜记忆限时剧情日常）及 `DailyClaim`（每日活跃宝箱与环游手册领奖）；同时保留轻量整合预设 `daily-routine`。
- **战斗与推进模块**：
  - **主线自动推进（实验性）**、**剧情跳过**、**自动编队**与**自动战斗**（快斩模式 / 权重出牌模式）。
  - **铁安局全自动**：提供「铁安局全自动（远程清 100%）」与「铁安局本地刷声望」双预设。
  - **区域作战中心自动推关**：支持低关卡短站点优先、敌方等级上限跳过、指定次数与澄明度安全收口。
  - **虚演刻录自动推关**：支持低敌方等级优先、未达成 S 级自动跳过与 0 门票安全退出。
- **PC 客户端与全局稳定性**：
  - 新增「PC 自动跑商（试用）」预设，并将所有新增自定义任务同步支持 PC 前台与后台控制器（使用前请在游戏进入可操作主界面后连接窗口，后台模式不可最小化游戏窗口）。
  - 新增 MXU 全局选项「断线弹窗自动重连守卫（全局）」（默认关闭，可在遇到网络不佳重连弹窗时辅助重试与恢复）。

### 使用与反馈

- 首次解压运行 `MaaResonance.exe` 后请先选择控制器与区服资源并核对任务开关与队伍配置。
- 本增强版问题请直接在本仓库 [Issues](https://github.com/JizhiShiroppu/MaaResonance/issues) 反馈（附带 MXU 日志、任务配置与出错界面截图），请勿提交到上游原仓库。
