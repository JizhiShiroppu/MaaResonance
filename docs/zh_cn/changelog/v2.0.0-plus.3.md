## v2.0.0-plus.3 社区衍生增强版

基于 [DaiMao204/MaaResonance](https://github.com/DaiMao204/MaaResonance) `v2.0.0-beta.2` 构建的社区衍生增强版（遵循 AGPL-3.0-only 开源协议）。

### 本版修复与优化

- **整顿中心（监狱）生产车间与配员修复**
  - **已有组长时自动跳过「车间编辑」**：当车间顶栏已识别到有效「车间组长」、本次运行未新办理囚犯入住且无需检查机台升级时，直接跳过「车间编辑」进入「生产」，大幅减少单次执行耗时与无效切换。
  - **修复多生产车间互相抢夺囚犯问题**：加强「快速编队 / 选择囚犯」2×6 网格筛选，拦截带有他室角标（`合1`/`金1`/`合2`/`金2`/`仓1`/`舍2` 及右下角被 OCR 误识的单字符）及截断状态字样（如「产中」）的卡片，防止 1 号与 2 号生产车间每轮互相抢人并清空原有组长。
  - **支持多槽顺序探测指派车间组长**：组长仍为「未设置」时，若 1 号槽位无驻留囚犯，自动依次探测 1～6 号工位直至找到「设为组长」按钮完成指派。
